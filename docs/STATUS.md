# מצב המימוש

## מומש ונבדק בפועל (Postgres 16 מקומי אמיתי, Chromium אמיתי במסך נייד)
- סכמה, RLS, הרשאות עמודה, נעילת `anon`, בידוד בין עסקים, מלאי הרשאות EXECUTE (בדיקות DB + אבטחה)
- מנוע זמינות (0009): נעילות מתואמות (idem→phone→biz→staff), מכסת טלפון תחת מקביליות, זמן מוחלט/חצות/DST ישראל, אידמפוטנטיות לניסיון חוזר, מניעת חפיפה ב-DB; שינוי זמינות לא נוגע בתורים קיימים ומחזיר רשימת מושפעים. לכל תיקון בדיקה שנכשלת על הקוד הישן
- אבטחה (0010): MFA ל-Super Admin נאכף ב-DB (aal2) + אימות טרי לפעולות חוצות-עסקים, bootstrap למנהל ראשון, ניהול בעלים ב-UI, Origin מפורש, יומן פעולות append-only בלי PII, תחזוקה מתוזמנת
- ריצה מלאה אחרונה: 80/80 בדיקות מקומיות + e2e דפדפן
- קישור אישי: טוקן אקראי, נשמר כ-hash, תפוגה, מגבלת שימושים, מגבלת ביטול
- הגבלת קצב באחסון משותף (IP / עסק / נייד, HMAC עם pepper)
- פניות (תבניות leads), השבתת עסק (ניתוק מיידי), ייצוא/ייבוא בין שני מסדים כולל המשכיות קישורים (5 בדיקות)
- שכבת API (14 בדיקות) מול DB אמיתי, כולל ניקוי חשבון Auth כשיצירת עסק נכשלת
- ממשק: הזמנה, ניהול, Super Admin, דף פניות – e2e בדפדפן
